# The Funniest One-Line Resignation Letter

Entry for the make.fun bounty "The Funniest One-Line Resignation Letter"
(u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

The program writes the cron job's one-line resignation letter to
`entry.txt` — one line, nothing else.

> I have fired every minute since March, and the only time anyone noticed me was when I stopped, so I am stopping for good.

121 characters. Run locally with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
